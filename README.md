# QSkill Task 1 - Pandas Data Analysis

## Objective
Load a CSV file using Pandas, calculate statistics, analyze categories/regions, and create a bar chart, scatter plot and heatmap.

## Run
```bash
pip install -r requirements.txt
python analysis.py
```

## Files
- `data/sales_data.csv` - dataset
- `analysis.py` - analysis and visualization program
- `outputs/` - generated charts

## Conclusion
The project demonstrates CSV loading, cleaning checks, descriptive statistics, grouping, aggregation and data visualization using Python.
